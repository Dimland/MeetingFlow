# Отклонения

- Проверка страницы через командный Playwright из плана заменена встроенным браузером приложения: в окружении отсутствует `npx`. Для пересмотра достаточно установить Node.js и повторить шаг через командную строку.
- Работа продолжается в текущей папке на уже созданной отдельной ветке `homework-kosher-eval-html`; дополнительное рабочее дерево не создаётся, чтобы не переносить начатые несохранённые изменения.
- Встроенный браузер заблокировал локальный адрес `file://` своей политикой безопасности. Вместо обхода ограничения выполнена расширенная проверка исходной разметки; визуальную проверку нужно повторить вручную.

# Обнаруженные крайние случаи

- Контрольные слова нужно проверять после удаления HTML-комментариев, иначе обычный поиск не отличает скрытый текст от видимого.
- При замене нумерованного списка маркированным остался лишний закрывающий тег `</ol>`; добавлена проверка количества тегов списков и ошибка исправлена.
- Общий запуск `dotnet test MeetingFlow.slnx --nologo` не является чистым: 6 из 7 интеграционных проверок микросервисов упали на пустых ответах или неожиданном состоянии конечной точки. Изменение касается только HTML и документов.
